    if (window.markdownitFootnote) {
        md.use(window.markdownitFootnote);
    }

    // Apply markdown-it-texmath plugin for KaTeX math rendering (XRND-01)

IMPORTANT: Do NOT change the existing `md.core.ruler.push('source_map', ...)` block — scroll sync depends on it.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CDN → assets/ | Third-party JS/CSS downloaded from jsdelivr.net at build time; served locally at runtime |
| markdown content → KaTeX renderer | User-authored LaTeX expressions processed by KaTeX in WebView2 |
| markdown content → texmath parser | Dollar-sign delimiters parsed by texmath before reaching KaTeX |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | CDN download | mitigate | Pin exact versions in URLs (katex@0.16.45, markdown-it-texmath@1.0.0, markdown-it-footnote@4.0.0); verify file sizes and known string content after download |
| T-03-02 | Information Disclosure | KaTeX font files | accept | Fonts served from appassets.mdpreview virtual host with DENY_CORS — already established pattern from Phase 2; no cross-origin leakage |
| T-03-03 | Spoofing | Math expression injection via $...$ | mitigate | `throwOnError: false` renders malformed math as inline error span, not thrown exception; KaTeX does not execute arbitrary JS; `html: false` on markdown-it remains in place |
| T-03-04 | Elevation of Privilege | Footnote anchor IDs conflicting with DOM | accept | Footnote anchors are internal hash links; they do not trigger SCN_UPDATEUI (C++ level) and do not bypass the WebView2 sandbox |
</threat_model>
