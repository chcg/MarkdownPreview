Required COM interfaces (already available via WebView2 SDK 1.0.3856.49):
- ICoreWebView2_7 (QueryInterface from m_webview) — provides PrintToPdf
- ICoreWebView2Environment6 (QueryInterface from m_environment) — provides CreatePrintSettings
- ICoreWebView2PrintSettings — page settings (width, height, orientation, margins, header/footer)
- ICoreWebView2PrintToPdfCompletedHandler — completion callback

ICoreWebView2_7::PrintToPdf signature:
  HRESULT PrintToPdf(LPCWSTR resultFilePath,
                     ICoreWebView2PrintSettings* printSettings,
                     ICoreWebView2PrintToPdfCompletedHandler* handler);

ICoreWebView2PrintSettings properties used:
  put_Orientation(COREWEBVIEW2_PRINT_ORIENTATION_PORTRAIT)
  put_ShouldPrintHeaderAndFooter(TRUE)   — enables auto header/footer
  put_HeaderTitle(LPCWSTR title)         — title portion of header (D-08: set to basename of .md file)
  put_ShouldPrintBackgrounds(TRUE)       — include background colors/images
  put_MarginTop(double inches)           — Claude's discretion: 0.5 inches
  put_MarginBottom(double inches)        — 0.5 inches
  put_MarginLeft(double inches)          — 0.75 inches
  put_MarginRight(double inches)         — 0.75 inches

Note on D-08 footer limitation (from RESEARCH.md Open Questions #1):
ICoreWebView2PrintSettings has FooterUri (shows document URI) but no custom footer string property.
ShouldPrintHeaderAndFooter=TRUE generates default footer: "[URI]  Page N of M".
The URI will be "https://appassets.mdpreview/preview.html" which is not ideal.
Mitigation: set HeaderTitle to the basename of the .md file (satisfies "filename in print output").
This gives: header = "basename.md", footer = "https://appassets.mdpreview/preview.html  Page N of M".
EXPT-03 requires "page numbers, headers, and footers" — this satisfies it (page numbers are present,
header contains filename, footer is present). Accept this limitation per research recommendation.

Add the following implementation. Place it AFTER the `saveExportedHtml()` method and BEFORE `handleJsMessage()`:

```cpp
// Phase 3: Trigger PDF export via WebView2 ICoreWebView2_7::PrintToPdf (EXPT-02, EXPT-03)
// D-06: Output path = source .md path with .pdf extension. Auto-save, no dialog, overwrite if exists.
// D-07: US Letter portrait, fixed — no user config.
// D-08: HeaderTitle = basename of .md file; ShouldPrintHeaderAndFooter=TRUE enables "Page N of M" footer.
// CRITICAL: m_environment must be set (done in initWebView2() environment callback by Plan 03).
void PreviewPanel::triggerPdfExport() {
    if (!m_webview || !m_webview2Initialized || m_currentFilePath.empty()) return;
    if (m_printToPdfInProgress) return;  // guard: ICoreWebView2_7::PrintToPdf — only one at a time

    // D-06: Derive PDF output path — replace .md extension with .pdf
    std::wstring pdfPath = m_currentFilePath;
    size_t dotPos = pdfPath.rfind(L'.');
    if (dotPos != std::wstring::npos) {
        pdfPath = pdfPath.substr(0, dotPos) + L".pdf";
    } else {
        pdfPath += L".pdf";
    }

    // D-08: Extract basename of .md file for HeaderTitle
    std::wstring basename = m_currentFilePath;
    size_t slashPos = basename.find_last_of(L"\\/");
    if (slashPos != std::wstring::npos) {
        basename = basename.substr(slashPos + 1);
    }

    // Get ICoreWebView2Environment6 from stored m_environment (set in initWebView2 env callback)
    if (!m_environment) return;
    wil::com_ptr<ICoreWebView2Environment6> env6;
    m_environment->QueryInterface(IID_PPV_ARGS(&env6));
    if (!env6) return;  // Pitfall 5: env6 null if m_environment was not stored

    // Create print settings
    wil::com_ptr<ICoreWebView2PrintSettings> printSettings;
    HRESULT hr = env6->CreatePrintSettings(&printSettings);
    if (FAILED(hr) || !printSettings) return;

    // D-07: US Letter portrait (8.5 x 11 inches). Portrait is the default orientation.
    // put_PageWidth and put_PageHeight default to 8.5 and 11.0 — explicit for clarity.
    printSettings->put_Orientation(COREWEBVIEW2_PRINT_ORIENTATION_PORTRAIT);

    // EXPT-03: Enable page numbers + header/footer
    printSettings->put_ShouldPrintHeaderAndFooter(TRUE);

    // D-08: Header = basename of .md file (e.g., "README.md")
    //       Footer = default URI + "Page N of M" (ICoreWebView2PrintSettings limitation — no custom footer string)
    printSettings->put_HeaderTitle(basename.c_str());
    // FooterUri left as default (shows appassets.mdpreview/preview.html + page number)

    // Include background colors (code blocks, Mermaid diagrams render with backgrounds)
    printSettings->put_ShouldPrintBackgrounds(TRUE);

    // Margins: Claude's discretion per D-08 context
    printSettings->put_MarginTop(0.5);     // 0.5 inch top margin
    printSettings->put_MarginBottom(0.5);  // 0.5 inch bottom margin
    printSettings->put_MarginLeft(0.75);   // 0.75 inch left margin
    printSettings->put_MarginRight(0.75);  // 0.75 inch right margin

    // Get ICoreWebView2_7 from m_webview for PrintToPdf method
    wil::com_ptr<ICoreWebView2_7> webview7;
    m_webview->QueryInterface(IID_PPV_ARGS(&webview7));
    if (!webview7) return;

    m_printToPdfInProgress = true;
    hr = webview7->PrintToPdf(
        pdfPath.c_str(),
        printSettings.get(),
        Callback<ICoreWebView2PrintToPdfCompletedHandler>(
            [this](HRESULT errorCode, BOOL isSuccessful) -> HRESULT {
                m_printToPdfInProgress = false;
                // D-06: Silent completion — no dialog, no notification on success or failure
                // errorCode and isSuccessful are intentionally unused
                UNREFERENCED_PARAMETER(errorCode);
                UNREFERENCED_PARAMETER(isSuccessful);
                return S_OK;
            }).Get());

    if (FAILED(hr)) {
        m_printToPdfInProgress = false;  // reset on immediate failure
    }
}
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| C++ menu handler → PrintToPdf | PDF output path is C++-derived (no JS input, no user input) |
| WebView2 renderer → PDF file | Chromium renders current preview HTML to PDF binary |
| PDF file → filesystem | PDF written to same directory as source .md file |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-15 | Tampering | PDF output path | mitigate | pdfPath is derived entirely from m_currentFilePath (set by NPPM_GETFULLCURRENTPATH — trusted NPP API); not derived from any JS message or user text input; path traversal via .md extension replacement is safe (we only replace the extension of a known .md path) |
| T-03-16 | Denial of Service | Concurrent PrintToPdf calls | mitigate | m_printToPdfInProgress flag guards against concurrent calls; set true before PrintToPdf, reset false in completion callback; second call returns immediately if flag is set (per ICoreWebView2_7 docs — concurrent calls fail immediately) |
| T-03-17 | Information Disclosure | Basename in PDF header | accept | Basename of the currently open .md file is set as HeaderTitle; this is the user's own file, visible to the user; no credentials or sensitive system paths in basename |
| T-03-18 | Elevation of Privilege | ICoreWebView2Environment6 QueryInterface | accept | QueryInterface on m_environment returns ICoreWebView2Environment6 only if runtime supports it (WebView2 SDK 1.0.1020.30+, which 1.0.3856.49 satisfies); null check guards against older runtimes |
| T-03-19 | Denial of Service | PDF written to read-only directory | accept | PrintToPdf completion callback returns isSuccessful=FALSE; failure is silent per D-06 (no dialog); user can retry after resolving permissions; no crash or hang |
</threat_model>
