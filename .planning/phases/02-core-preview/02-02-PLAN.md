                existing.id = 'custom-css';

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Markdown content → innerHTML | md.render() output is assigned to .innerHTML. markdown-it with html:false sanitizes raw HTML passthrough. |
| External CDN → local assets | JS/CSS files downloaded from cdn.jsdelivr.net at pinned versions and stored locally. No runtime CDN requests from WebView2. |
| Custom CSS content → style tag | User-provided CSS injected as a style tag. Can affect layout but cannot exfiltrate data or execute JS. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-06 | Tampering | md.render() → innerHTML | mitigate | markdown-it initialized with `html: false` — raw HTML blocks in markdown are escaped, not passed through. Prevents XSS via markdown content. Per ASVS L1 requirement for output encoding. |
| T-02-07 | Tampering | Custom CSS injection | accept | User-controlled CSS is applied as a `<style>` tag in a sandboxed WebView2 context. CSS cannot execute scripts or read file system. Risk is low: only affects visual appearance. No PII or credentials at risk. |
| T-02-08 | Information Disclosure | Asset download (CDN) | mitigate | Assets downloaded once at development time from pinned CDN URLs (cdn.jsdelivr.net), stored locally in assets/. WebView2 serves them via virtual host — no outbound network requests at runtime. |
| T-02-09 | Tampering | markdown-it-task-lists UMD | accept | If the downloaded UMD build has unexpected global name, task-list rendering silently degrades (checkboxes not rendered). Mitigated by inspection check in Task 1 acceptance criteria. Not a security issue — cosmetic only. |
</threat_model>
