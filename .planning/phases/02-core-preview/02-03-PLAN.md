```cpp
void onScnUpdateUi(SCNotification* notification) {
    // Only sync on caret/selection changes — not on scroll events
    // SC_UPDATE_SELECTION = 0x02; SC_UPDATE_CONTENT = 0x01
    if (!(notification->updated & (SC_UPDATE_SELECTION | SC_UPDATE_CONTENT))) return;

    // Get active Scintilla handle
    int sciId = 0;
    ::SendMessage(nppData._nppHandle, NPPM_GETCURRENTSCINTILLA, 0,
        reinterpret_cast<LPARAM>(&sciId));
    HWND hSci = (sciId == 0) ? nppData._scintillaMainHandle
                              : nppData._scintillaSecondHandle;

    // Get byte position of caret, then convert to 0-indexed line number
    Sci_Position caretPos = static_cast<Sci_Position>(
        ::SendMessage(hSci, SCI_GETCURRENTPOS, 0, 0));
    int caretLine = static_cast<int>(
        ::SendMessage(hSci, SCI_LINEFROMPOSITION,
            static_cast<WPARAM>(caretPos), 0));

    // Only send scroll if a .md file is active and panel is visible
    if (!g_previewPanel.isVisible()) return;
    wchar_t path[MAX_PATH] = {};
    ::SendMessage(nppData._nppHandle, NPPM_GETFULLCURRENTPATH, MAX_PATH,
        reinterpret_cast<LPARAM>(path));
    std::wstring filePath(path);
    bool isMd = filePath.size() >= 3 &&
        (_wcsicmp(filePath.c_str() + filePath.size() - 3, L".md") == 0);
    if (isMd) {
        g_previewPanel.scrollToLine(caretLine);
    }
}
```

```javascript
function scrollToLine(line) {
    // Find the element with the highest data-line value that is <= target line
    // Elements are in document order so we can stop at the first element > target
    var elements = document.querySelectorAll('[data-line]');
    if (!elements.length) return;

    var best = null;
    for (var i = 0; i < elements.length; i++) {
        var elLine = parseInt(elements[i].getAttribute('data-line'), 10);
        if (elLine <= line) {
            best = elements[i];
        } else {
            break;
        }
    }
    // Per UI-SPEC Interaction Contract D-04: smooth scroll, block start
    if (best) {
        best.scrollIntoView({ behavior: 'smooth', block: 'start' });
    }
    // If no element found: no scroll, no error (per D-04 spec)
}
```

```cpp
void PreviewPanel::updateFileVirtualHost(const std::wstring& filePath) {
    if (!m_webview) return;

    // Extract parent directory from file path
    std::wstring dir = filePath;
    size_t pos = dir.find_last_of(L"\\/");
    if (pos != std::wstring::npos) {
        dir = dir.substr(0, pos);
    } else {
        return;  // no directory component — skip
    }

    wil::com_ptr<ICoreWebView2_3> webview3;
    m_webview->QueryInterface(IID_PPV_ARGS(&webview3));
    if (!webview3) return;

    // Clear existing mapping before setting new one (Pitfall 3 mitigation)
    // ClearVirtualHostNameToFolderMapping is safe even if no mapping exists
    webview3->ClearVirtualHostNameToFolderMapping(L"file.mdpreview");
    webview3->SetVirtualHostNameToFolderMapping(
        L"file.mdpreview",
        dir.c_str(),
        COREWEBVIEW2_HOST_RESOURCE_ACCESS_KIND_DENY_CORS);
}
```

```javascript
// Rewrite relative image paths to use file.mdpreview virtual host (D-08, REND-05)
// Handles: ./img.png, subdir/img.png, ../img.png
// Leaves unchanged: http://, https://, //, and data: URIs
function rewriteImagePaths(markdownText) {
    return markdownText.replace(
        /!\[([^\]]*)\]\((?!https?:\/\/|\/\/|data:)(\.?\.?\/?)([^)]+)\)/g,
        function(match, alt, prefix, rest) {
            // Normalize: strip leading ./ if present
            var normalized = (prefix + rest).replace(/^\.\//, '');
            return '![' + alt + '](https://file.mdpreview/' + normalized + ')';
        }
    );
}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| File system → WebView2 | file.mdpreview virtual host exposes the current file's parent directory to the WebView2 renderer. |
| Editor caret position → JS | Caret line number (integer) is sent via PostWebMessageAsJson. Benign data — no path or content traversal possible. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-10 | Information Disclosure | file.mdpreview virtual host | mitigate | Host is set with COREWEBVIEW2_HOST_RESOURCE_ACCESS_KIND_DENY_CORS — prevents cross-origin requests from fetching files via the virtual host. Only the preview page itself can load images. Mapping is reset on every file switch so it only points to the current file's directory. |
| T-02-11 | Elevation of Privilege | rewriteImagePaths() path traversal | mitigate | Regex only rewrites markdown image syntax paths that do not start with http/https/data. The virtual host itself is mapped with DENY_CORS. WebView2 sandbox prevents the JS from accessing arbitrary file system paths outside the mapped directory. |
| T-02-12 | Denial of Service | SCN_UPDATEUI frequency | accept | SCN_UPDATEUI fires on every keystroke and every caret move. Each event sends a small JSON message (~30 bytes). PostWebMessageAsJson is async and non-blocking. No accumulation risk for normal usage. Performance impact is negligible. |
| T-02-13 | Tampering | Scroll line injection via editor | accept | The line number sent in the scroll message is derived from SCI_GETCURRENTPOS which reflects the actual caret position — it cannot be spoofed externally. The JS receiver clamps to available data-line elements. |
</threat_model>
