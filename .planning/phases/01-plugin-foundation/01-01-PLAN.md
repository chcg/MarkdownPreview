**PluginInterface.h** — Standard Notepad++ plugin interface header containing:
- `NppData` struct with `_nppHandle` and `_scintillaMainHandle` and `_scintillaSecondHandle` (all HWND)
- `FuncItem` struct with `_itemName` (wchar_t[64]), `_pFunc` (PFUNCPLUGINCMD = void(*)() ), `_cmdID` (int), `_init2Check` (bool), `_pShKey` (ShortcutKey*)
- `ShortcutKey` struct with `_isCtrl`, `_isAlt`, `_isShift` (bool) and `_key` (UCHAR)
- Required: `#define NPPMSG (WM_USER + 1000)` and key message IDs

**Notepad_plus_msgs.h** — Notepad++ message constants:
- `NPPM_DMMSHOW (NPPMSG + 30)`
- `NPPM_DMMHIDE (NPPMSG + 31)`
- `NPPM_DMMREGASDCKDLG (NPPMSG + 33)`
- `NPPM_SETMENUITEMCHECK (NPPMSG + 40)`
- `NPPM_GETPLUGINSCONFIGDIR (NPPMSG + 46)`
- `NPPM_GETPLUGINHOMEPATH (NPPMSG + 49)`
- Notification constants: `NPPN_FIRST 1000`, `NPPN_READY (NPPN_FIRST+1)`, `NPPN_SHUTDOWN (NPPN_FIRST+11)`, `NPPN_TBMODIFICATION (NPPN_FIRST+2)`

**Docking.h** — Docking constants and tTbData struct:
- `DWS_DF_CONT_LEFT 1`, `DWS_DF_CONT_RIGHT 2`, `DWS_DF_CONT_TOP 4`, `DWS_DF_CONT_BOTTOM 8`
- `DWS_ICONTAB 0x00000001`, `DWS_ICONBAR 0x00000002`
- `tTbData` struct: `hClient` (HWND), `pszName` (const wchar_t*), `dlgID` (int), `uMask` (UINT), `hIconTab` (HICON), `pszAddInfo` (const wchar_t*), `rcFloat` (RECT), `iPrevCont` (int), `pszModuleName` (const wchar_t*)

**Scintilla.h** — Minimal Scintilla header with `SCNotification` struct (nmhdr + position, ch, modifiers, etc). Download or create minimal version with the fields needed for `beNotified`.

**menuCmdID.h** — Define `IDM 40000` base for menu command IDs.

**PluginDefinition.h:**
```cpp
#pragma once
#include "PluginInterface.h"

const int NB_FUNC = 1;  // One menu item: Toggle Preview
const wchar_t PLUGIN_NAME[] = L"MarkdownPreview";

void pluginInit(HANDLE hModule);
void pluginCleanUp();
void commandMenuInit();
void commandMenuCleanUp();

// Menu command
void togglePreview();
```

**PluginDefinition.cpp:**
- Store `NppData nppData` (global)
- Store `HINSTANCE hInstance` (global, from DllMain)
- `pluginInit()`: save hModule as hInstance
- `pluginCleanUp()`: empty for now
- `commandMenuInit()`: set up funcItems[0] with name "Toggle Preview", function pointer `togglePreview`, shortcut Ctrl+Shift+M (per D-08: `ShortcutKey{ true, false, true, 'M' }`)
- `commandMenuCleanUp()`: empty
- `togglePreview()`: stub -- just `MessageBox(NULL, L"MarkdownPreview toggle", L"MarkdownPreview", MB_OK)` for now (replaced in Plan 02)

**PluginMain.cpp:**
- `DllMain`: store hInstance, return TRUE
- Six `extern "C" __declspec(dllexport)` functions:
  - `setInfo(NppData data)` — stores nppData, calls pluginInit
  - `getName()` — returns PLUGIN_NAME (L"MarkdownPreview")
  - `getFuncsArray(int* nbF)` — sets *nbF=NB_FUNC, returns funcItems
  - `isUnicode()` — returns TRUE
  - `beNotified(SCNotification* notification)` — handles NPPN_READY, NPPN_SHUTDOWN, NPPN_TBMODIFICATION (stubs)
  - `messageProc(UINT msg, WPARAM wp, LPARAM lp)` — returns TRUE
- Also add a .def file or ensure exports are visible (dllexport is sufficient)

**Critical:** All functions must use `extern "C" __declspec(dllexport)` with exact names. Notepad++ looks these up by name.
