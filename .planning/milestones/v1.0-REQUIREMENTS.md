# Requirements: MarkdownPreview v1.0

**Defined:** 2026-04-08
**Core Value:** Open a markdown file, see it beautifully rendered in real-time as you type — no context switching, no external tools.

## v1 Requirements

### Core Rendering

- [x] **REND-01**: Preview panel auto-opens as a dockable Notepad++ panel when a .md file is opened — Phase 2, `NPPN_BUFFERACTIVATED` handler
- [x] **REND-02**: Preview updates live as the user types (debounced for performance) — Phase 2, 300ms `SetTimer/KillTimer` debounce
- [x] **REND-03**: Full GFM support — tables, fenced code blocks, task lists, strikethrough, autolinks — Phase 2, markdown-it 14.1.1 with GFM preset
- [x] **REND-04**: Syntax highlighting in fenced code blocks with language auto-detection — Phase 2, highlight.js 11.11.1
- [x] **REND-05**: Local images render correctly with relative path resolution against the file's directory — Phase 2, `file.mdpreview` virtual host mapping
- [x] **REND-06**: YAML frontmatter is hidden from rendered output — Phase 2, `stripFrontmatter()` pre-parse

### Extended Rendering

- [x] **XRND-01**: Math/LaTeX expressions render via KaTeX (inline and block) — Phase 3, KaTeX 0.16.45 + markdown-it-texmath 1.0.0
- [x] **XRND-02**: Mermaid diagrams render from fenced code blocks (flowcharts, sequence, Gantt, etc.) — Phase 3, mermaid 11.14.0 IIFE bundle
- [x] **XRND-03**: Footnotes render with proper numbering and back-references — Phase 3, markdown-it-footnote 4.0.0
- [x] **XRND-04**: Code blocks include a copy-to-clipboard button (GitHub-style) — Phase 3, `injectCopyButtons()` with `navigator.clipboard`

### Themes & Styling

- [x] **THME-01**: Dark and light themes bundled out of the box — Phase 2, github-markdown-css 5.9.0 light + dark + hljs github themes
- [x] **THME-02**: User can provide custom CSS to style the preview — Phase 2, `setCustomCss()` inline style injection
- [x] **THME-03**: Preview theme auto-detects Notepad++ dark/light mode — Phase 2, `NPPN_DARKMODECHANGED` + `NPPM_ISDARKMODEENABLED`
- [x] **THME-04**: Zoom controls (Ctrl+/Ctrl- or toolbar, 80-800%) — Phase 3, `AcceleratorKeyPressed` + `document.body.style.zoom` with settings persistence

### Scroll & Navigation

- [x] **SCRL-01**: Preview scroll position syncs with editor caret position — Phase 2, `SCN_UPDATEUI` → `scrollToLine()` → `data-line` nearest-element scroll
- [x] **SCRL-02**: Clicking in the preview scrolls the editor to the corresponding source line — Phase 4, JS `data-line` click → `SCI_GOTOLINE`
- [x] **SCRL-03**: Clickable table of contents generated from document headings — Phase 4, `buildToc()` + `updateTocActive()` + flex sidebar

### Export

- [x] **EXPT-01**: Export rendered markdown to standalone HTML file (with inlined CSS) — Phase 2, `exportHtml()` + base64 images + Ctrl+Shift+E
- [x] **EXPT-02**: Export rendered markdown to PDF via WebView2 — Phase 3, `ICoreWebView2_7::PrintToPdf` + Ctrl+Shift+P
- [x] **EXPT-03**: Print output includes page numbers, headers, and footers — Phase 3, `ICoreWebView2PrintSettings` header/footer configuration

### Plugin Infrastructure

- [x] **INFR-01**: Toggle show/hide preview panel via menu item and keyboard shortcut — Phase 1, `NPPM_DMMREGASDCKDLG` + Ctrl+Shift+M
- [x] **INFR-02**: Plugin loads correctly in both 32-bit and 64-bit Notepad++ — Phase 1, dual x86/x64 build configurations
- [x] **INFR-03**: Graceful handling when WebView2 runtime is not installed — Phase 1, `GetAvailableCoreWebView2BrowserVersionString` detection + SysLink fallback
- [x] **INFR-04**: Publish-ready quality — proper installer, versioning, plugin list compatible — Phase 4, `VS_VERSION_INFO` resource, `manifest.json`, `package.ps1`

## Out of Scope

| Feature | Reason |
|---------|--------|
| Markdown editing toolbar/ribbon | Preview plugin, not an editor enhancement |
| WYSIWYG/inline rendering | Incompatible with Scintilla-based editor |
| Weblog publishing | Full application feature, not preview plugin concern |
| AI features (grammar, summarize) | Requires API keys, cloud services, ongoing maintenance |
| Collaborative editing | Notepad++ is a single-user desktop tool |
| File import/transclusion | Niche feature, security concerns |
| Non-Windows platform support | Notepad++ is Windows-only |
